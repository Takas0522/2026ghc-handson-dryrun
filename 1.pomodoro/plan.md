# ポモドーロタイマー 段階的実装計画

各フェーズは**動作確認可能な状態**で完了するよう設計しています。

---

## Phase 1: プロジェクト基盤 + 静的UI

**ゴール**: Flask サーバーが起動し、モックに近い静的なUIがブラウザに表示される

| 対象機能 | 内容 |
|---|---|
| B-1 | `create_app()` アプリファクトリ |
| B-2 | `GET /` ルーティング |
| H-1 | ウィンドウ風ヘッダー |
| H-2 | モード表示エリア（「作業中」固定表示） |
| H-3 | SVG 円形タイマー（`25:00` 固定表示、プログレスリング100%） |
| H-4 | 操作ボタン（見た目のみ） |
| H-5 | 今日の進捗カード（固定値表示） |
| S-1〜S-7 | CSS スタイル全般 |

**確認方法**: `flask run` でサーバー起動 → ブラウザでモックと見比べて外観を確認

---

## Phase 2: タイマーロジック（純粋関数）+ テスト

**ゴール**: `timer.js` の全純粋関数が実装され、ユニットテストが通る

| 対象機能 | 内容 |
|---|---|
| L-1 | `createInitialState()` |
| L-2 | `formatTime(seconds)` |
| L-3 | `tick(state)` |
| L-4 | `completePomodoro(state)` |
| L-5 | `nextMode(state)` |
| L-6 | `resetTimer(mode)` |
| L-7 | `calcProgress(state)` |
| L-8 | 集中時間フォーマット |
| T-2〜T-8 | 上記すべての JS ユニットテスト |

**確認方法**: Jest / Vitest でテスト全件パス

---

## Phase 3: UI層 − タイマーの開始・停止・表示更新

**ゴール**: 「開始」ボタンでカウントダウンが動き、時間表示とプログレスリングがリアルタイム更新される

| 対象機能 | 内容 |
|---|---|
| U-1 | 開始 / 一時停止 |
| U-3 | タイマー表示更新（毎秒） |
| U-4 | 円形プログレスバー更新（毎秒） |
| U-9 | `setInterval` によるタイマー駆動 |

**確認方法**: ブラウザで「開始」→ カウントダウンが動く、再度押すと一時停止

---

## Phase 4: UI層 − リセット・モード遷移・進捗表示

**ゴール**: 全機能が動作する完成版アプリ

| 対象機能 | 内容 |
|---|---|
| U-2 | リセットボタン |
| U-5 | モード表示切替（「作業中」↔「休憩中」） |
| U-6 | 自動モード遷移（作業25分→休憩5分→作業...） |
| U-7 | 今日の進捗 − 完了数表示 |
| U-8 | 今日の進捗 − 集中時間表示 |

**確認方法**: タイマー完了→自動で休憩モードに遷移、進捗カードの数値が更新される

---

## Phase 5: Flask テスト + 最終調整

**ゴール**: バックエンドテスト追加、全体の品質確認

| 対象機能 | 内容 |
|---|---|
| T-1 | Flask ルーティングテスト |
| − | UIの微調整（モックとのズレ修正） |
| − | エッジケース対応（0秒でのtick等） |

**確認方法**: `pytest` でバックエンドテストパス、ブラウザで一連の操作フローを通しで確認

---

## 全体像

```
Phase 1  ──→  Phase 2  ──→  Phase 3  ──→  Phase 4  ──→  Phase 5
 基盤+静的UI    ロジック+テスト   タイマー動作    全機能統合    テスト+調整
 (B,H,S)       (L,T)           (U一部)        (U残り)      (T残り)
```

## フェーズ分けの考え方

| 原則 | 説明 |
|---|---|
| **見た目を先に** | Phase 1 で静的UIを完成させ、ゴールの形を早期に可視化する |
| **ロジックをUIより先に** | Phase 2 でテスト付きのロジックを固め、Phase 3 以降はUI層がロジックを呼ぶだけにする |
| **段階的に動くものを作る** | 各フェーズ終了時にブラウザまたはテストで動作確認できる |
| **コア機能を先、周辺機能を後** | Phase 3 でタイマーの核（開始・カウントダウン）を先に動かし、Phase 4 でリセット・遷移・進捗を追加 |
