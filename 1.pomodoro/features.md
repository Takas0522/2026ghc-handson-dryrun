# ポモドーロタイマー 実装機能一覧

## バックエンド（Flask）

| # | 機能 | 詳細 |
|---|---|---|
| B-1 | アプリファクトリ | `create_app()` で Flask アプリを生成 |
| B-2 | ルーティング | `GET /` で `index.html` を返す |

## フロントエンド - ロジック層（`timer.js`）

| # | 機能 | 詳細 |
|---|---|---|
| L-1 | 初期状態の生成 | `createInitialState()` でモード・残り時間・完了数等を初期化 |
| L-2 | 時間フォーマット | `formatTime(seconds)` で秒数を `MM:SS` 形式に変換 |
| L-3 | タイマーtick | `tick(state)` で残り時間を1秒減算した新しい状態を返す |
| L-4 | ポモドーロ完了処理 | `completePomodoro(state)` で完了数+1、集中時間を加算 |
| L-5 | モード遷移 | `nextMode(state)` で作業→休憩、休憩→作業を切り替え（休憩は5分、作業は25分） |
| L-6 | タイマーリセット | `resetTimer(mode)` で現在のモードの初期時間に戻す |
| L-7 | プログレス計算 | `calcProgress(state)` で経過割合（0〜1）を算出 |
| L-8 | 集中時間のフォーマット | 合計集中秒数を「X時間Y分」形式に変換 |

## フロントエンド - UI層（`ui.js`）

| # | 機能 | 詳細 |
|---|---|---|
| U-1 | タイマー開始/一時停止 | 「開始」ボタンでカウントダウン開始、再度押すと一時停止 |
| U-2 | タイマーリセット | 「リセット」ボタンで現在のタイマーを初期値に戻す |
| U-3 | タイマー表示更新 | 毎秒 `MM:SS` の表示を更新 |
| U-4 | 円形プログレスバー更新 | SVG `stroke-dashoffset` を毎秒更新してリングを描画 |
| U-5 | モード表示切替 | 「作業中」/「休憩中」のテキストをモードに応じて切り替え |
| U-6 | 自動モード遷移 | タイマー完了時に自動で次のモード（作業↔休憩）へ遷移 |
| U-7 | 今日の進捗 - 完了数表示 | 完了したポモドーロ数を表示 |
| U-8 | 今日の進捗 - 集中時間表示 | 合計集中時間を「X時間Y分」形式で表示 |
| U-9 | `setInterval` によるタイマー駆動 | 1秒間隔で `tick` を呼び出し、状態とUIを更新 |

## テンプレート / HTML（`index.html`）

| # | 機能 | 詳細 |
|---|---|---|
| H-1 | ウィンドウ風ヘッダー | 「ポモドーロタイマー」タイトルとウィンドウコントロール風装飾（ー □ ×） |
| H-2 | モード表示エリア | 「作業中」/「休憩中」テキストの配置 |
| H-3 | SVG 円形タイマー | `<svg>` + `<circle>` でプログレスリングと中央の時間テキスト |
| H-4 | 操作ボタン | 「開始」ボタン（塗りつぶし）+「リセット」ボタン（アウトライン） |
| H-5 | 今日の進捗カード | 完了数と集中時間を表示するセクション |

## スタイル / CSS（`style.css`）

| # | 機能 | 詳細 |
|---|---|---|
| S-1 | 紫系グラデーション背景 | ページ全体の背景（`#6C63FF` 系） |
| S-2 | カード型レイアウト | 中央配置・丸角・影付きのメインカード |
| S-3 | 円形プログレスバーのスタイル | SVG リングの色・太さ・アニメーション |
| S-4 | 開始ボタンスタイル | 紫系塗りつぶし、丸角のボタン |
| S-5 | リセットボタンスタイル | 紫系アウトライン、丸角のボタン |
| S-6 | 今日の進捗セクション | グレー背景、完了数・集中時間の2カラムレイアウト |
| S-7 | タイマー時間テキスト | 大きなフォントサイズ、太字、中央配置 |

## テスト

| # | 機能 | 詳細 |
|---|---|---|
| T-1 | Flask ルーティングテスト | `GET /` が200を返し、ページ内に「ポモドーロタイマー」が含まれるか |
| T-2 | `formatTime` テスト | 各種秒数で正しいフォーマットが返されるか |
| T-3 | `tick` テスト | 残り時間が正しく1秒減算されるか |
| T-4 | `completePomodoro` テスト | 完了数と集中時間が正しく加算されるか |
| T-5 | `nextMode` テスト | 作業→休憩、休憩→作業の遷移と時間設定が正しいか |
| T-6 | `resetTimer` テスト | 各モードで初期時間にリセットされるか |
| T-7 | `calcProgress` テスト | 経過割合が正しく算出されるか（0%、50%、100%） |
| T-8 | 集中時間フォーマットテスト | 秒数→「X時間Y分」の変換が正しいか |
